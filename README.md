# iam-governance-analysis
iam-governance-analysis


This project demonstrates an identity governance review conducted within a commercial real estate access control environment.

The initiative analyzes credential lifecycle risks, identity sprawl, and governance gaps within a building access control system.

Objective

Introduce identity governance concepts to improve visibility and lifecycle management of access credentials.

Key goals:

identify duplicate identities

identify dormant credentials

identify unused active credentials

highlight governance gaps

Environment Overview

Commercial property access control environment.

Approximate scale:

1,389 active credentials

300 duplicate identities identified

Multiple categories of identity sprawl detected.

Identity Risk Categories

The analysis identified four major credential states:

Compliant Access

Dormant Credentials

Unused Active Credentials

Shared Credentials

These categories help illustrate access lifecycle risks commonly addressed through identity governance frameworks.

Key Findings

The review identified several areas where governance controls could improve credential lifecycle management.

Examples include:

duplicate identities

inactive credentials remaining active

shared credentials

These conditions increase identity risk exposure and complicate audit visibility.

Governance Recommendations

The analysis recommends implementation of:

centralized identity governance

periodic access reviews

credential lifecycle controls

identity ownership policies

These controls align with common IAM governance practices used in enterprise environments.

Purpose

This case study represents a generalized identity governance analysis conducted within a commercial access control environment. All data has been anonymized and recreated for demonstration purposes.
This repository demonstrates IAM governance analysis techniques used to identify identity sprawl and improve access control visibility within growing operational environments.
